# Initiative template

Copy the `.template` files into a new `architecture/initiatives/<epic-id>/`
directory, removing the suffix and replacing `<epic-id>`. Copy
`README.md.template` as the initiative README. Add an agreed model and focused
views before validating. Empty templates are intentionally incomplete and are
not discovered as entrypoints. No disconnected-placeholder exception is granted.

The workspace extends the shared model, with reference-only missing-view
exceptions. Every local element must appear in a connected view. Use stable
identifiers, proposal evidence/status properties and `<epic-id>-` view keys.
Variants extend the initiative and use `<epic-id>-<variant>-` for new view keys.

Follow the [contribution workflow](../../../README.md#contributing-an-initiative).
