# Accepted platform modules

This directory is reserved for reviewed platform system definitions. It initially
contains no DSL definitions: `dapp_platform` belongs to ignition. Existing
FireFly, Besu, security, operations and application examples remain references;
they do not define the new platform's ownership.

After review, move accepted definitions here, preserve identifiers, and add
explicit shared includes before relationships. Remove old initiative definitions
in the same change and validate every workspace.
