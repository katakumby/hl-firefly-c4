# Historical material

This directory preserves the previous generator, deployment archive, documents,
reports and exports. Retired scripts are historical source, not runnable
maintenance commands. Their paths describe the former repository layout.

The [pre-migration catalog](pre-modular-catalog.json) is an immutable migration
baseline, not an editable model or input to ordinary validation. The one-time
semantic comparison confirms the initial migration preserved 333 elements,
696 relationships and 95 views. Future reviewed architecture changes need not
match this historical snapshot.

The [deployment archive](archive/README.md) preserves historical DSL fragments
and placement data. Active workspaces do not load or validate them.

Current commands are in the [root README](../../../README.md).
