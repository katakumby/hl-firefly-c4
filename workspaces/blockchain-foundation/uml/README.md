# Initiative UML diagrams

Place standalone `.puml` and `.mmd` behavioral or code diagrams here.
`build-source` copies them beneath `build/source/workspaces/blockchain-foundation/uml/`.
The independent [preview stages](../../../README.md#build-previews-independently)
render generated PlantUML or Mermaid to SVG and PNG in the matching
`build/preview/workspaces/blockchain-foundation/uml/` tree.
